# Components Documentation

## Component Structure

```
src/components/
├── ui/              # Basic UI components
├── features/        # Feature components
├── layouts/         # Layout components
└── shared/          # Shared components
```

## UI Components

Basic reusable components:
- Button
- Input
- Card
- Modal
- Toast

## Feature Components

Components with business logic:
- TransactionList
- AIAnalyzer
- ReportGenerator
- DocumentUploader

## Best Practices

1. Use TypeScript for all components
2. Add PropTypes or interfaces
3. Write unit tests for each component
4. Follow composition principles
5. Use React hooks correctly
